## Unreleased

## 0.5.0 - 2026-10-24

- Windows x64 portable release with Qt/VC/MuJoCo runtimes, buildable source, synthetic examples, licenses and SHA-256 verification.
- FBX/glTF import and animation export, textures, eight-weight skinning and morph targets.
- FK/IK posing, reviewed humanoid profiles, directed joint limits, contacts, live symmetry and grouped edits with Undo/Redo.
- Ordered correction layers, independent component keys, scalar/SO(3)/Euler curves and a native Qt Graph Editor.
- Motion paths, numerical measurements, comparison, geometric diagnostics and calibrated humanoid retargeting with independent result documents.
- Bone/frame notes, searchable context, Timeline navigation and 42 authenticated native HTTP MCP tools.
- Persistent documents, atomic saving, separate recovery autosaves, indexed GPU skinning and CPU fallback.
- Experimental native MuJoCo tools for whole-body/COM posing, flight and bounded dynamics correction. The 62 scientific reliability gates remain open; regression success does not certify dynamics.
- Current user/developer guides, explicit package payloads without duplicate resources, and Windows toolchain discovery. Local character libraries are excluded from public packages.
