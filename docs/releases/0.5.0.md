# Trickster 0.5.0

Windows x64 portable release. Extract the complete ZIP and run Trickster.exe.

- Graph Editor with scalar, quaternion and Euler channels, key/tangent editing and shared Timeline selection.
- Motion paths, measurements, comparison and geometric diagnostics.
- Calibrated humanoid retargeting with independent result documents.
- Quick notes: select a bone, Ctrl+Alt+N, type, Ctrl+Enter. Searchable dock, bone-following markers, Timeline navigation and full author text through MCP.
- Indexed GPU skinning, CPU fallback and fixes for camera/document ownership and metadata Undo.
- 42 native HTTP MCP tools; Python is optional for the stdio bridge only.

Product version comes from CMakeLists.txt. Source/project schema 8 reads schemas 1-8. A release is built from the exact clean Git commit identified by BUILD-INFO.txt. The package includes Qt, VC and native MuJoCo runtimes, licenses, source and synthetic example projects. Private/local character libraries are excluded; import your own FBX, GLB or glTF characters.

## Validation

The release validation attachment records the exact clean source commit, executable identity, archive checksum, complete CTest result and extracted-package smoke checks. See [testing commands](../TESTING.md) and the [notes workflow](../NOTES.md).

The optional [historical evidence archive](https://github.com/Atmosaero/Trickster/releases/download/v0.5.0/Trickster-0.5.0-validation-evidence.zip) preserves earlier measurement snapshots and failed scientific gates with their original build identities. Those historical records are distinct from validation of this release and do not certify physics.

## Known limits

Physics remains experimental: the 62 scientific acceptance gates remain open. Editor regression success is not a dynamics certificate. Godot FBX import can smooth Step animation; independently checked GLB preserves the tested Step behavior. Notes drafts are not saved until confirmed, markers are hidden during playback, and the current-moment filter refreshes when playback stops. At 1280 x 720 and 150%, advanced card fields use scrolling. Other operating systems are not validated for this release.
